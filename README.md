### Development of a Healthcare Operations Intelligence Dashboard with Decision Analytics

### 📌 Project Overview

This repository contains the end-to-end development of a **Healthcare Operations Intelligence Dashboard** designed as part of the **Infosys Springboard Internship** program. 

The primary objective of this project is to apply decision analytics to healthcare operational data. By transforming fragmented raw data into structured, interactive visual dashboards, this solution helps hospital administrators optimize resource allocation, track patient flow, monitor departmental efficiency, and improve overall operational decision-making.

### ⚙️ Project Workflow & Lifecycle

### 1. Data Retrieval & Preprocessing

* **Raw Data:** Sourced healthcare metrics detailing operational parameters.
* **Data Cleaning:** Handled missing values, eliminated duplicate rows, standardized date formats, and engineered necessary operational fields using Python scripts (data_cleaning/).

### 2. Exploratory Data Analysis (EDA)

* Analyzed data distributions, patterns, and operational bottlenecks.
* Outlined core variables influencing key performance indicators (KPIs) like patient wait times, bed occupancy rates, and departmental throughput.

### 3. Decision Analytics & Dashboards

Developed 5 distinct operational dashboards focusing on: 

* **Dashboard 1:** Patient Flow Analytics & Admission Tracking
* **Dashboard 2:** Resource & Bed Occupancy Optimization
* **Dashboard 3:** Departmental Throughput & Staffing Efficiency
* **Dashboard 4:** Operational Cost & Financial Metrics
* **Dashboard 5:** Clinical Outcome & Quality Care Analytics

### 🚀 Key Takeaways & Impact

* **Actionable Insights:** Transformed raw operational logs into clear, actionable executive visual summaries.
* **Bottleneck Identification:** Highlighted key departments suffering from operational delays.
* **Resource Optimization:** Provided a framework to dynamically allocate clinical resources based on data-driven historical patterns.
